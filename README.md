# mot-application-logger

> **DEPRECATED: no longer maintained.**
>
> This package has been superseded by [dvsa/mot-logger](https://github.com/dvsa/mot-logger),
> which combines `mot-logger` and `mot-application-logger` into a single Monolog-based library.
> Do not use this package for new work. This repository will be archived (read-only)
> following MTS release 5.85.0.

Utility for logging MOT Web App and API exceptions to defined formats.

## Installing

The recommended way to install is through [Composer](https://getcomposer.org/).
```
composer require dvsa/mot-application-logger
```
